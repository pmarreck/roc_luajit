# History

Fork-era documents, kept verbatim. They describe how the backend was built while
it lived in a fork of Roc. They are not maintained.

- `INTENT.md`: the original brief and M0 acceptance criteria.
- `ARCHITECTURE.md`: the code-cited M0 report (§1–9) and the decision log (§10).
  The decision log is still the rationale behind `design.md`.
- `PLAN.md`: the dated progress log and requests.

Their `path:line` citations refer to upstream roc-lang/roc `64ee0aeddc`, and
their relative links predate this layout. `SPEC.md` now lives at `../SPEC.md`.
Current docs are `README.md`, `design.md` and `TODO.md` at the repository root.
